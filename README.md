# TT-02 改裝助手（PWA）

## 功能
- 零件清單：新增、編輯、刪除、標示想買／已購買／已安裝。
- 預算：設定總預算、運費與其他費用；勾選零件後即時加總。
- 改裝紀錄：記錄日期、項目、花費、狀態與備註。
- 資料備份：匯出／匯入 JSON。
- PWA：manifest、service worker、圖示，部署至 HTTPS 後可安裝並快取離線使用。

## 如何測試
最簡單的方式：在電腦或手機瀏覽器開啟 `index.html`，零件清單、預算和紀錄功能即可使用。部分瀏覽器對本機檔案的 PWA 安裝與離線快取有限制。

## 如何安裝成 PWA
1. 將整個資料夾部署至支援 HTTPS 的靜態網站主機（例如 GitHub Pages、Netlify 或其他 HTTPS 主機）。
2. 確認 `index.html`、`manifest.webmanifest`、`sw.js`、`icon-192.png`、`icon-512.png` 都位於同一目錄。
3. 在 Android Chrome 開啟網站，從瀏覽器選單選「安裝應用程式」或「加到主畫面」。選項依瀏覽器版本而異。

## 重要限制
- 本版本不會自動抓取購物網站的價格、庫存或運費，也不會自動下單。
- 範本零件價格預設為 0，避免把過期或未驗證的價格誤當成目前報價；請自行輸入賣場確認後的價格。
- 範本購買按鈕會開啟搜尋頁，不代表特定商品已核實可買或已確認相容。
- 資料存在目前瀏覽器 localStorage。清除瀏覽器資料可能造成資料遺失，請定期匯出 JSON 備份。
- 非 Tamiya 官方應用程式。請核對 TT-02、TT-02B、TT-02D 等版本差異及原廠零件資料。

## 檔案
- `index.html`：App 本體
- `manifest.webmanifest`：PWA 設定
- `sw.js`：離線快取
- `icon.svg`、`icon-192.png`、`icon-512.png`：圖示
